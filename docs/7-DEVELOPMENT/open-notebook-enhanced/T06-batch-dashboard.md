# T06 Batch管理・検索可能状態UI

- Issue: [#10](https://github.com/AiraCometes/open-notebook/issues/10)

- API仕様: [T02](T02-embedding-status-api.md)、[T03](T03-batch-worker.md)、[T04](T04-job-controls.md)
- 後続タスク: T12

## 目的

大量資料の処理状況を俯瞰し、検索できる範囲と現在の遅れを利用者が判断できるようにする。

## 作業範囲

- Batchジョブの待機中、処理中、完了、失敗の集計と一覧を表示する。
- ジョブ詳細に資料数、チャンク進捗、失敗数、作成・開始時刻を表示する。
- 権限と状態に応じて一時停止、再開、キャンセル、失敗分再試行を操作できる。
- Search/Ask画面に検索可能チャンク数、処理中件数、失敗件数を表示する。
- 進捗更新は初期版ではポーリングで行い、画面離脱時は不要な取得を止める。

## 受け入れ条件

- ジョブ一覧と集計がバックエンド状態に一致する。
- 実行可能な操作だけが表示され、操作結果が画面に反映される。
- Embedding未完了時に検索範囲が不完全な可能性を示す。
- API障害や空状態を理解可能なメッセージで表示する。
- 大量ジョブでも一覧操作が実用的である。

## 完了条件

ジョブ管理画面と検索画面の状態表示が統合されている。
