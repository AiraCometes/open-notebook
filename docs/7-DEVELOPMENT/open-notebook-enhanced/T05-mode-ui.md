## 目的

資料追加時に通常・Batch・自動を選び、資料一覧で選択モードと進捗を判別できるようにする。

## 作業範囲

- 資料追加フローに3つのモード選択肢と短い説明を追加する。
- 既定モードを設定できるようにする。初期値は通常処理とする。
- 自動判定の閾値と判定理由を利用者に説明できる形で管理する。
- 資料一覧にモードバッジ、状態、完了数/総数、失敗数を表示する。
- APIへ選択値を渡し、既存アップロード経路との互換性を保つ。

## 受け入れ条件

- 利用者が資料追加時に通常、Batch、自動を選択できる。
- 選択したモードが資料一覧と詳細で一貫して見える。
- 自動選択時は最終的に適用されたモードが確認できる。
- ローディング、未開始、処理中、失敗、完了の表示が状態APIと一致する。
- キーボード操作と画面幅の小さい場合でも選択・状態確認ができる。

## 完了条件

画面、API連携、主要状態表示のフロントエンドテストが揃っている。
